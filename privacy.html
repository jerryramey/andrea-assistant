Privacy Policy

Last updated: November 10, 2026

Andrea Assistant is a private application used only by its owner, Jerry Ramey. It has no other users.

What it accesses

With the owner's permission, it reads the owner's own Google Calendar using read-only access (calendar.readonly). It cannot create, change or delete calendar events.

How the data is used

Calendar data is used only to show the owner his own availability and plan his own time. It is processed on the owner's private server and is not sold, shared or transferred to anyone else, and is not used for advertising.

Storage and deletion

Access credentials are stored with owner-only file permissions on the owner's private server. The owner can revoke access at any time at myaccount.google.com/permissions, which stops all access.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: open an issue at github.com/jerryramey/andrea-assistant.
